✈ Flight Finder – MERN Stack Project

📌 Overview

Flight Finder is a full-stack Navigating  your air travel options developed as part of the SmartInternz Internship Program.
The project demonstrates practical implementation of MERN stack technologies by building a real-world airline booking system with authentication, admin controls, and dynamic data handling.


🚀 Features

- ✈ Search and book flights by origin, destination, and date
- 🔐 User authentication and authorization system
- 🧾 Admin dashboard for managing flights
- 💬 Responsive and interactive UI built with React
- 🌐 RESTful API architecture using Express & Node.js


🛠 Tech Stack

Frontend

- React.js
- Bootstrap

Backend

- Node.js
- Express.js

Database

- MongoDB

Tools & Platforms

⚙ Installation & Setup

1️⃣ Clone Repository

git clone https://github.com/kapireddygariharika/FlightFinder.git
cd flight-finder

2️⃣ Install Dependencies

Backend

cd server
npm install

Frontend

cd ../client
npm install


3️⃣ Run Application

Start Backend Server

cd server
npm start

Start Frontend

cd client
npm start


🔐 Environment Variables

Create a ".env" file inside the server folder and add:

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
